Workflow Summary

Phase 1: Generate Task Checklists

Prompt: /generate-repo-task-checklists

  • Reads repository URLs from repositories.txt
  • Creates one *_repo_checklist.md file per repository
  • Defines 6 sequential tasks to be executed for each repo

Phase 2: Execute Repository Tasks

Prompt: /execute-repo-task

  • Processes each repository through the 6-task pipeline
  • Clones repositories to local directory
  • Analyzes README files and extracts setup commands
  • Discovers all solution files (*.sln)
  • Generates solution-specific task checklists
  • Outputs: cloned repos, task results, solution checklists

Phase 3: Execute Solution Tasks

Prompt: /execute-solution-task

  • Processes each discovered solution through 10-task pipeline
  • Restores dependencies and builds solutions
  • Captures build errors and creates knowledge base entries
  • Iteratively fixes build errors (up to 1 attempts)
  • Retries builds after each fix attempt
  • Outputs: built solutions, error documentation, fix attempts
